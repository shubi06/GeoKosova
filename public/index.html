GeoKosova

Hidhesh në një pikë të rastit të Street View brenda territorit të Kosovës dhe duhet t'ia qëllosh vendin në hartë. Sa më afër, aq më shumë pikë.

Ruhet vetëm në localStorage të shfletuesit tënd — nuk shkon asgjëkund tjetër. Duhen aktive dy API: Maps JavaScript API (përfshin Street View) dhe Geocoding API.

Pa kartë krediti: versioni me Mapillary · Me shokë: multiplayer (kërkon serverin lokal)

Si e marr një API key? (falas, ~5 minuta)
  1. Hap console.cloud.google.com/google/maps-apis/start dhe hyr me llogarinë e Google.
  2. Krijo një projekt të ri — emërtoje geokosova.
  3. Aktivizo Maps JavaScript API (Street View vjen brenda tij) dhe Geocoding API nga APIs & Services → Library.
  4. APIs & Services → Credentials → + Create credentials → API key. Kopjoje dhe fute lart.
  5. Kliko Edit API key dhe kufizoje: Application restrictions → Websites → shto http://localhost:8765/*; te API restrictions zgjidh vetëm dy API-të e mësipërme. Kështu nuk mund t'i përdorë kush tjetër.
  6. Google kërkon një llogari faturimi me kartë, por kuota falas mujore është e bollshme (shih më poshtë). Vendos edhe një budget alert te Billing → Budgets & alerts për siguri.
Sa shpenzon kjo lojë? (kuota falas)
  1. Dynamic Street View — 5 000 panorama falas/muaj, pastaj $14 / 1 000. Kjo është kufizimi kryesor: 1 panoramë për raund.
  2. Dynamic Maps — 10 000 ngarkime falas/muaj, pastaj $7 / 1 000. Kjo lojë hap 2 harta për sesion të faqes, jo për raund.
  3. Geocoding — 10 000 falas/muaj, pastaj $5 / 1 000. Një thirrje për raund, për emrin e vendit.
  4. Në praktikë: një lojë me 5 raunde ≈ 5 panorama + 5 geocoding. Kjo do të thotë rreth 1 000 lojëra në muaj pa pagesë.
  5. Kërkimi i vendit nuk kushton — StreetViewService.getPanorama() merr vetëm metadata dhe nuk faturohet, pra tentativat e loja bën për të mos dalë jashtë Kosovës janë falas.
  6. Kujdes vetëm me modin Lehtë: çdo hap që bën nëpër rrugë ngarkon panoramë të re dhe numërohet veç. Modi Normal ose Vështirë mban një panoramë për raund.
